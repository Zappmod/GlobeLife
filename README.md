# GlobeLife

This repo contains the sample application and interactive lab guide site for the IBM Bob Premium Package for Z Workshop — Globe Life.

## Contents

| Folder | Description |
|--------|-------------|
| `PagesSite/` | React + Vite lab guide website hosted on GitHub Pages |
| `Labs/` | Lab content and supporting materials |
| `Sample Code/` | GenApp COBOL sample application used in the labs |
| `CleanUpBob4z/` | Cleanup utilities for Bob for Z |
